    01 — What it does

    Fewer steps between
    thought and note.

    Searchevery keystroke

    Instant, incremental search

    Every note filters as you type: titles, bodies and tags, thousands of notes, no waiting. The best match is already selected, so reading is one keystroke away and writing is zero.

    Hotkeyanywhere

    Summon it from anywhere

    Pick a global shortcut and Notational drops in over whatever you’re doing.

    ⌘⇧L
    Markdownlive

    Write plain, read pretty

    Markdown and MultiMarkdown with a live preview window, plus TaskPaper lists. Save any note as HTML.

    SyncSimplenote

    Your phone, too

    Sign in with an emailed code and your notes sync with Simplenote, with a three-way merge when you edit on two devices at once.

    Menu baroptional

    Out of the way

    Run it from the menu bar with no Dock icon. It’s there when you call it and gone when you don’t.

    Local firstoffline

    Works without an account

    Notes live in a local database on your Mac and work offline. Sync is optional. Export to plain text, rich text, HTML or Word whenever you like.

    Coming from nvALT?one-time

    Bring everything

    On first launch it imports your nvALT notes and settings once, and never touches the old files.

    04 — Install

    Get it running.

    Build from source

    All you need is Xcode. The build compiles MultiMarkdown too, and leaves the app in build/.

    $ git clone --recursive https://github.com/gsiener/notational $ cd notational $ scripts/install.sh # builds and copies it to ~/Applications

    First launch

    Builds you make yourself aren’t notarised, so macOS may say it can’t check the app. Right-click Notational, choose Open, then confirm. You only need to do this once.

    Prebuilt downloads will appear on the releases page.
